## 1. Descripción

Este proyecto corresponde al Primer Parcial de la asignatura Inteligencia Artificial.
Se realiza un análisis exploratorio de un conjunto de datos meteorológicos correspondiente a un periodo de 12 días.
Las variables disponibles son:

- Fecha
- Temperatura en °C
- Precipitación en mm
- Humedad relativa en %

El objetivo es identificar problemas de calidad en los datos, realizar análisis estadístico, generar visualizaciones e interpretar las relaciones entre las variables.
